# Customer Churn & Retention Analysis

## Project Overview

This project analyzes customer churn and retention patterns using Python and data analysis techniques.

The analysis identifies customer groups with higher churn rates and examines the relationship between churn, subscription plans, customer demographics, tenure, support calls, and monthly charges.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The dataset contains 30 customer records with information including:

- Customer ID
- Gender
- Age
- City
- Subscription Plan
- Monthly Charges
- Tenure
- Support Calls
- Churn Status

## Analysis Performed

- Dataset structure and data quality analysis
- Churn rate calculation
- Churn analysis by subscription plan
- Churn analysis by city
- Churn analysis by gender
- Churn analysis by age group
- Average tenure by churn status
- Average support calls by churn status
- Average monthly charges by churn status
- Identification of high-risk customers

## Visualizations

The project includes visualizations for:

- Customer churn distribution
- Churn by subscription plan
- Churn by city
- Churn by gender
- Churn by age group
- Monthly charges by churn status

## Key Business Insights

- Identified customer segments with higher churn rates.
- Analyzed the relationship between customer tenure and churn.
- Examined support-call patterns among churned customers.
- Compared churn across different subscription plans and cities.
- Identified high-risk customers based on churn status and support interactions.
